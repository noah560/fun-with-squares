# Fun with Squares
Fun with Squares is an open-source voxel-based survival game written in Rust.
Its main differences that make it unique compared to Mincraft or Luanti are the builtin software ray-tracer(WIP)
and the scaling, where each individual cell is very small.
This game was inspired by Teardown, Luanti, Sandboxels, and Minecraft.

## Attribution
A lot of this is based on the learn-wgpu tutorial by sotrh on github.

## Progress
I now have rendering, which I will still improve. I do
not have controls or connection to a game server yet.
The current released version has a simple demo that
shows the current rendering and chunk loading.
